⚙ Configure GitHub Source
The dashboard reads data/accounts.json from your GitHub repo
1
Create a public GitHub repo (or use an existing one) and clone it locally.
2
Run bash run.sh inside the StorageIQ folder. It authenticates, fetches real data, and pushes data/accounts.json to your repo.
3
Enter your username/repo below, then click Connect. The dashboard fetches live JSON on every load and on every Refresh click.
4
Optional: push to GitHub and the included .github/workflows/sync.yml auto-syncs every 6 hours, committing a new version each time.
Settings are saved in your browser's localStorage.
